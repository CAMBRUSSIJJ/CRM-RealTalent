REALTALENT CRM V100.46.4 — PACOTE LIMPO PARA GITHUB/VERCEL

1. No GitHub Desktop, abra o repositório CRM-RealTalent.
2. Acesse Repository > Show in Explorer.
3. Faça uma cópia da pasta atual como backup.
4. Preserve a pasta oculta .git.
5. Substitua os outros arquivos pelo conteúdo desta pasta.
6. No GitHub Desktop, use Commit to main e depois Push origin.

No Vercel, mantenha:
Root Directory: ./
Output Directory: dist

VITE_SUPABASE_URL=https://SEU-PROJETO.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=SUA_CHAVE_PUBLICAVEL
