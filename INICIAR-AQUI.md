# Iniciar — RealTalent CRM V100.48

1. Use Node.js 22.
2. Copie `.env.example` para `.env.local` e configure as variáveis necessárias.
3. Execute `npm install` quando estiver usando o projeto completo.
4. Rode `npm run dev` para desenvolvimento ou `npm run build` para gerar a publicação.
5. A V100.48 não exige migration nova. Para o RealTalent Connect, confirme que `202607280005_v100_46_5_connect_call_sessions.sql` já foi publicada.
6. Para validação, rode as auditorias de identificadores, renderização e ações profissionais.

Documentação principal: `docs/FONTE-OFICIAL-V100-48.md`, `docs/PLANO-HOMOLOGACAO-V100-48.md` e `docs/ACOES-PROFISSIONAIS-V100-48.md`.
