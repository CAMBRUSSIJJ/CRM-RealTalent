# Iniciar — RealTalent CRM V100.46.5

1. Copie o conteúdo desta pasta para a raiz do repositório GitHub.
2. Faça `Commit to main` e `Push origin` pelo GitHub Desktop.
3. No Vercel, mantenha `Root Directory` como `./`; o `vercel.json` já define build e saída.
4. Configure `VITE_DATA_MODE=supabase`, `VITE_SUPABASE_URL` e `VITE_SUPABASE_PUBLISHABLE_KEY`.
5. Publique a migration `202607280005_v100_46_5_connect_call_sessions.sql` no Supabase.
6. Abra o RealTalent Connect com a mesma conta e organização.
7. No CRM, entre em Ligações → Começar sessão → Atualizar dispositivos.
8. Use **Personalizar** para escolher quais painéis e ferramentas ficarão visíveis.

Documentação: `docs/CENTRAL-DE-LIGACOES-V100-46-5.md`.
