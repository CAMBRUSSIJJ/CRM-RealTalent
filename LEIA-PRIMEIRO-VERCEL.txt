REALTALENT CRM V100.46.4 — PUBLICAÇÃO NO VERCEL

1. Copie todo o conteúdo desta pasta para a raiz do repositório.
2. Faça Commit to main e Push origin no GitHub Desktop.
3. No Vercel, deixe Root Directory como ./ e Output Directory como dist.
4. Não crie Install Command manual.
5. O vercel.json executa: node scripts/build-registry-independent.mjs
6. Aguarde o novo deployment ficar Ready.

Variáveis necessárias para dados reais:
VITE_DATA_MODE=supabase
VITE_SUPABASE_URL=https://SEU-PROJETO.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=SUA_CHAVE_PUBLICA

Nunca use service_role, senha do banco ou segredo OAuth no frontend.
