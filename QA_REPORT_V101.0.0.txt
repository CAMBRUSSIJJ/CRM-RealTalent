LIMITAÇÕES DE VALIDAÇÃO
- O container desta sessão não possui todas as dependências npm em cache e o registry externo
  não ficou acessível. `npm ci --offline` falhou por pacote não armazenado (xmlchars 2.2.0).
- Portanto, não é correto afirmar que o Vite build/typecheck/Vitest completos foram executados
  neste container.
- O start-linux.sh executa npm ci/install, preflight e o BUILD REAL do Vite no Linux do usuário
  antes de abrir o navegador. Se o build falhar, o CRM não é iniciado.
- Google Geocoding/Places não foram chamados ao vivo porque nenhuma chave do usuário foi fornecida.
- Chamadas PSTN reais dependem das credenciais do provider configuradas no RealTalent Connect.
