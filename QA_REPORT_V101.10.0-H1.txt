RealTalent CRM V101.10.0-H1 — Settings Registry Preflight Hotfix
QA Report
================================================================

Causa corrigida
---------------
O Experience Registry de Settings ainda publicava seletores legados:
  .settings-v16__hero
  .settings-v16__body

A Settings Experience 2.0 usa os alvos atuais:
  .settings-v1100__header
  .settings-v1100__body

O Linux release preflight validava corretamente que os seletores expostos em
Configurações > Páginas apontassem para elementos TSX reais, portanto a release
V101.10.0 falhava antes do typecheck.

Correção
--------
- Experience Registry atualizado para os alvos V101.10.0 reais;
- layout legado NÃO foi reintroduzido;
- preflight continua rejeitando seletores órfãos;
- gate específico H1 adicionado;
- launcher H1 migra a sessão diretamente da V101.10.0 quando disponível.
