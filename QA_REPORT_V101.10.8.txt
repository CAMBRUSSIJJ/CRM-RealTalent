COMPORTAMENTO ESPERADO NA PRIMEIRA EXECUÇÃO COM INTERNET
1. start.mjs valida o lock.
2. Detecta inconsistência.
3. Remove node_modules parcial, se existir.
4. Executa npm install --no-fund --no-audit uma única vez.
5. Revalida package-lock.json.
6. Verifica as dependências runtime críticas.
7. Persiste hash do lock.
8. Nas execuções seguintes, usa npm ci quando a árvore precisar ser reconstruída.
