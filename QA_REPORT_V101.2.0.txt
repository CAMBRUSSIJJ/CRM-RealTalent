LIMITAÇÃO DE VALIDAÇÃO NESTE AMBIENTE
O npm registry não ficou disponível de forma confiável. Uma tentativa de npm ci online expirou e o modo offline confirmou ausência do pacote xmlchars-2.2.0 no cache. Portanto, não foi possível executar aqui o typecheck completo do projeto, a suíte Vitest completa e o build Vite de produção da V101.2.

O launcher mantém esses gates obrigatórios no Linux do usuário:
preflight -> todos os QA -> typecheck completo -> Vitest -> build Vite -> bundle audit -> HTTP smoke -> RealTalent Connect smoke -> inicialização.
Se qualquer etapa falhar, o CRM não abre.

LIMITAÇÃO TÉCNICA EXPLÍCITA DO REALTALENT PHONE
O companion V101.2 é uma aplicação web local, não um APK/IPA nativo. Ele consegue receber o comando do CRM e abrir o discador do celular via tel:, mas navegadores móveis não podem controlar automaticamente uma chamada SIM nativa. Por isso, atendimento/não atendimento/término são confirmados no companion. Para controle integral da chamada pelo software, use um provider PSTN como o Twilio Agent Bridge.

SEGURANÇA
- CRM continua servido somente em 127.0.0.1.
- Connect escuta a LAN para permitir o celular, mas a Voice API exige origem local autorizada.
- Endpoints de lista/pareamento administrativo são restritos ao CRM local.
- tokens dos dispositivos não são expostos na lista de devices.
- arquivo persistente de devices é criado com permissão 0600.
- nenhuma chave Twilio é enviada ao navegador.
