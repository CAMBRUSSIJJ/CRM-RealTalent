Typecheck / Vitest / build globais
---------------------------------
A montagem não possui node_modules. Uma tentativa de `npm install --no-audit --no-fund`
ficou bloqueada por timeout de rede e não criou node_modules. O typecheck global
foi iniciado e reportou módulos ausentes (`react`, `react-dom`, `lucide-react`,
`@supabase/supabase-js` e respectivos tipos), com erros de tipagem em cascata.
Por isso Vitest e build globais não foram executados neste ambiente.

O `start-linux.sh` mantém o gate completo no Linux do usuário:
npm install -> preflight -> release:verify/check -> typecheck -> Vitest -> build -> runtime smokes.
