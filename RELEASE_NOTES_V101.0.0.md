# V101.0.0 — Territory & UI System

- Território 3.0 sem dependência dos tiles CARTO que exibiam `API KEY REQUIRED`.
- OpenStreetMap como renderer base estável para Claro, Ruas e Escuro.
- Gateway local `/api/maps/geocode` com Google Geocoding API quando `GOOGLE_MAPS_SERVER_KEY` está configurada.
- Diagnóstico `/api/maps/diagnostics` e nova área `Configurações > Mapa e Território`.
- `configure-google-maps.sh` unifica configuração de Geocoding + Places.
- Rotas externas das contas/prospects abrem Google Maps.
- UI System V101 padroniza tipografia, botões, inputs, painéis, modais, foco, dark mode e responsividade.
- RealTalent Connect 3.0, Visual Intelligence, Garimpo e Layout Studio preservados.
