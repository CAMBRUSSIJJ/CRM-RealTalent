# Recuperação de desastre — V100.43

A recuperação segue o procedimento V100.42 com quatro entidades adicionais: produtos, propostas, itens de proposta e receitas. Antes de restaurar em homologação, valide checksums, organização de destino e dependências de lead/oportunidade. Propostas aceitas não devem ser reprocessadas manualmente; restaure os dados e execute os contratos SQL para impedir duplicidade de receita.
