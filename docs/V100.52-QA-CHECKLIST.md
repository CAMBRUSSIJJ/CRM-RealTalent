## Pipeline

- [ ] `npm ci` conclui sem erros.
- [ ] `npm run syntax:audit` passa.

- [ ] Base com mais de 1.000 leads carrega além do primeiro range.

## Realtime

- [ ] Alterar um lead em outra sessão atualiza Leads sem recarregar todos os domínios.

- [ ] Alterar evento atualiza Agenda.
- [ ] Alterar proposta/itens atualiza Propostas.
- [ ] Alterar produto/receita atualiza o slice correspondente.
