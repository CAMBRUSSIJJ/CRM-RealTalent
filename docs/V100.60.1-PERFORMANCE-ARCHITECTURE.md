# V100.60.1 — Performance & Architecture

## Objetivo

Reduzir custo de renderização e acoplamento do frontend sem alterar comportamento comercial, banco ou formato de backup.

## Decisões

1. **Context slicing:** navegação, workspace, UI e ações possuem providers específicos. `useApp()` permanece somente como ponte de compatibilidade.
2. **Stable action facade:** ações usam wrappers estáveis que delegam para a implementação mais recente do provider.
3. **Lazy call workspace:** o módulo pesado de ligação não participa mais do chunk normal das páginas que apenas oferecem o botão “Ligar”.
4. **Route CSS:** CSS comercial novo é carregado com Leads/Propostas/Ligações, não no bootstrap global.
5. **Legacy CSS modular:** o monólito foi separado mantendo a ordem de importação para preservar a cascata antes de qualquer remoção agressiva de CSS histórico.
6. **Application services:** automações e restore de backup não ficam mais embutidos no React Context.
7. **Repository decomposition:** seed/storage/guards locais e mapeadores Supabase foram isolados em módulos próprios.

## Política de segurança da refatoração

Nenhuma migration foi reescrita, nenhuma dependência de runtime foi adicionada e o schema de backup não foi elevado. Remoção de CSS foi limitada a duplicatas exatas conhecidas; CSS possivelmente legado foi modularizado, não apagado por heurística.
