# V100.66.0 — Buyer Room / Mutual Action Plan

## Arquitetura

A Buyer Room é uma entidade comercial vinculada a `Lead → Opportunity → Proposal → Company`. Ela não substitui a proposta: coordena o fechamento e registra engajamento do comprador.

### Fluxo interno

1. vendedor abre uma proposta vigente;
2. cria/abre a Buyer Room no Proposal 360;
3. revisa participantes, documentos e Mutual Action Plan;
4. ativa o link e opcionalmente define expiração;
5. comprador acessa `?buyer-room=<token>` sem autenticação;
6. abertura, documentos, comentários e etapas alimentam a timeline;
7. Deal Intelligence usa esses sinais para risco, engajamento e Next Best Action.

## Modelo

`BuyerRoom` contém:

- referências do negócio (`leadId`, `opportunityId`, `proposalId`, `companyId`);
- título e mensagem de abertura;
- `shareToken`, `shareEnabled`, expiração e telemetria de visualização;
- participantes;
- etapas do Mutual Action Plan;
- documentos;
- timeline de atividades.

## Segurança do link público

- token com 24 bytes aleatórios (48 caracteres hexadecimais);
- RLS continua protegendo a tabela;
- acesso externo ocorre apenas por funções `SECURITY DEFINER` com validação do token;
- privilégios padrão `PUBLIC EXECUTE` são revogados;
- funções públicas são concedidas somente a `anon` e `authenticated` quando necessário;
- link precisa estar ativo, não arquivado e dentro do prazo;
- a resposta pública não retorna dados internos do workspace;
- comprador só pode alterar etapas `buyer` ou `shared`.

## Revisões e merge

Ao criar revisão de proposta, a Buyer Room existente é retargetada para a nova revisão e o documento vinculado é atualizado. No merge de Leads, o modo local migra referências diretamente e o Supabase usa `merge_duplicate_leads_v10066`, que retargeta as salas antes do merge transacional legado e reconcilia oportunidade/empresa depois.

## Deal Intelligence

Sinais positivos:

- Buyer Room aberta;
- Mutual Action Plan >= 50% concluído.

Riscos:

- link compartilhado há pelo menos dois dias sem abertura;
- etapa do comprador/compartilhada bloqueada.

Esses sinais não substituem o Deal Health existente; entram na dimensão de engajamento e no Risk Engine explicável.

## Modo local

A página pública existe, porém o link funciona somente no mesmo navegador/computador porque a base é LocalStorage/IndexedDB. A UI informa isso explicitamente. Para compartilhamento externo, use Supabase em uma implantação web.
