# V100.67.0 — RealTalent Assistant

## Princípios
1. Grounding: toda resposta deriva do `WorkspaceSnapshot` atual.
2. Explicabilidade: scores e prioridades reutilizam o motor de Deal Intelligence.
3. Least privilege: consultas são somente leitura; mutações requerem plano e confirmação.
4. Determinismo primeiro: os intents críticos funcionam sem API/LLM.
5. Separação de responsabilidades: o Assistant decide/organiza; repositories continuam sendo a única camada de persistência.

## Intents iniciais
- `priorities`
- `risk_deals`
- `call_now`
- `proposal_followup`
- `missing_decision_maker`
- `stale_deals`
- `forecast`
- `lead_summary`
- `create_followups`

## Execução
`create_followups` usa o conjunto de leads retornado pela consulta anterior. Antes da confirmação o CRM recalcula elegibilidade e remove contatos inativos, DNC ou com follow-up equivalente já pendente.

## Privacidade
V100.67.0 opera localmente sobre o snapshot já carregado no cliente. Nenhum prompt ou dado comercial é enviado para um provedor externo.
