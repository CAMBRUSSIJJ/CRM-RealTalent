# RealTalent Voice & Dialer — V100.73

## Contrato do bridge

### Capabilities
`GET /api/voice/v1/capabilities`

Resposta esperada:
```json
{
  "schema": "realtalent.voice.capabilities.v1",
  "capabilities": {
    "outbound": true,
    "inbound": true,
    "callerId": true,
    "mute": true,
    "hold": true,
    "keypad": true,
    "transfer": true,
    "voicemailDrop": false,
    "recording": false
  }
}
```

### Iniciar chamada
`POST /api/voice/v1/calls` com schema `realtalent.voice.call.v1`.

### Comandos
`POST /api/voice/v1/calls/:callId/commands` com `command`: `answer`, `hangup`, `mute`, `unmute`, `hold`, `resume`, `dtmf`, `transfer` ou `voicemail_drop`.

### Eventos
O bridge pode publicar `realtalent.voice.event.v1` por `window.postMessage` (same-origin/localhost) ou disparar `CustomEvent('realtalent:voice-event')` quando integrado no mesmo runtime.

## Fallback
Sem Voice API compatível, o CRM mantém `external_tel`, abre `tel:` e exige confirmação manual de atendimento/resultado. Controles de áudio ficam desabilitados.
