# V100.74.0 — Functional Audit & Reliability Baseline

## Objetivo

Criar uma fonte única de verdade dentro do CRM para diferenciar interface visível de capability realmente implementada.

## Regra de classificação

### Funcional
Existe fluxo de leitura/escrita ou cálculo real conectado ao repositório/serviço do CRM e há contratos de QA para os comportamentos críticos.

### Parcial
Existe implementação relevante, mas o fluxo depende de configuração externa, possui fallback limitado, ou ainda exige correção/validação específica antes de ser considerado completo.

### Visual apenas
A interface existe, porém não há operação real correspondente. A V100.74 não identificou módulos principais ativos nessa condição; o estado permanece disponível para evitar regressões futuras.

### Não implementado
A capability ainda não existe operacionalmente. O caso principal nesta versão é a IA generativa própria do RealTalent Assistant.

## Princípios

1. modo demonstração não conta como integração externa ativa;
2. deep link para WhatsApp não conta como WhatsApp Business API;
3. estrutura OAuth no código não significa conta conectada;
4. estimativa local no mapa não é geocodificação exata;
5. Assistant determinístico não é apresentado como LLM generativo;
6. toda capability deve declarar limitação e próximo passo;
7. a matriz passa a fazer parte do QA da release.
