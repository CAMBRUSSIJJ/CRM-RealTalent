# Workspace Personalization V100.95.0

A versão separa **estrutura de navegação** de **estrutura de página**. A navegação decide onde cada módulo aparece; a Central de Páginas decide quais blocos aparecem dentro de cada módulo. Ambas usam preferências persistentes e normalização compatível com versões anteriores.

## Navegação

- Menu principal
- Mais ferramentas
- Oculto
- Ordem customizável
- Rótulo customizável

## Páginas

- Densidade
- Ênfase
- Escopo no Meu Dia
- Mostrar/ocultar bloco
- Reordenar bloco
- Restaurar página

## Forecast

Os blocos do Revenue Intelligence são registrados como seções independentes dentro da rota Propostas para que a mesma infraestrutura de experiência possa controlar KPIs, cenários, cobertura, riscos, responsáveis, origem/produto, conversão e negócios.
