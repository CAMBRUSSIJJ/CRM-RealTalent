# RealTalent CRM V101.0.0 — Territory & UI System

## Objetivo
Estabilizar o território comercial e consolidar um design system visual sem alterar os fluxos de Pipeline, Calling, Garimpo ou Visual Intelligence.

## Território 3.0
- Renderização: Leaflet + tiles padrão do OpenStreetMap.
- Nenhum tile CARTO; portanto o mapa-base não exibe `API KEY REQUIRED`.
- Modos Claro, Ruas e Escuro usam o mesmo provider estável com tratamento visual local.
- Rotas externas abrem Google Maps por URL pública sem exigir API key.
- Coordenadas já persistidas no CRM continuam tendo prioridade.

## Geocodificação e Places
Uma única `GOOGLE_MAPS_SERVER_KEY` pode habilitar:
- Google Geocoding API para endereço -> latitude/longitude no Território.
- Places API (New) para o Garimpo.

No Linux execute:
```bash
./configure-google-maps.sh
./start-linux.sh
```
A chave permanece no processo Vite/gateway local e não entra no bundle do navegador.

No modo Supabase, a Edge Function `geocode-lead` continua sendo a fonte de geocodificação hospedada.

## Fallback seguro
Sem chave Google:
- mapa continua visível via OpenStreetMap;
- coordenadas salvas/manuais continuam funcionando;
- registros sem coordenadas usam estimativa local marcada como aproximada;
- Garimpo Maps permanece em fluxo assistido.

## UI System V101
Padronização global de:
- tipografia e hierarquia;
- alturas de controles;
- botões e icon buttons;
- campos e selects;
- cards/panels;
- modais;
