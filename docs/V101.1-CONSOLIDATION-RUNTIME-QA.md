# V101.1 — Consolidation & Runtime QA

Esta versão fecha regressões de contrato e torna o processo de inicialização Linux um release gate verificável.

## Escopo
1. Compatibilidade histórica de versão.
2. Contrato de backup.
3. Coerência de rotas e navegação.
4. Boot guard e Error Boundary.
5. Bundle de produção sem CDN legado.
6. Smoke HTTP do build.
7. Preservação do mapa OSM/Leaflet e Google opcional.
8. Preservação do Calling 3.0 e RealTalent Connect.
9. Preservação de personalização, Guided Selling, Forecast e Garimpo.

## Critério de saída
Nenhuma nova feature entra nesta release. A versão só é aprovada quando o pacote passa pelos gates executáveis no ambiente alvo.
