# V101.10.2-H1 — Prospecting Agent UX & Launch Flow

## Objetivo

Fazer o usuário iniciar o Garimpo automático sem confundir o Motor local com Google Places ou com a API técnica do Agent.

## Fluxo principal

1. O CRM verifica o Agent em `127.0.0.1:4319`.
2. O usuário informa segmento, região, meta e recorrência dentro do bloco **Motor local**.
3. **Iniciar garimpo no Linux** cria um job local persistente.
4. O Agent pesquisa OpenStreetMap/Overpass, visita sites públicos e enriquece os resultados permitidos.
5. O CRM acompanha o job, permite pausar/cancelar e importa resultados concluídos para Revisão.

## Painel local

A rota `/` do Agent agora é uma página HTML de diagnóstico e atividade. Endpoints JSON continuam sob `/api/prospecting-agent/*`.

## Recuperação de conexão

O botão de início faz uma nova tentativa de health-check antes de informar que o Agent está desconectado. O launcher também detecta um Agent antigo e tenta substituí-lo pela versão H1.

## Fontes secundárias

Google Maps/Places, Instagram, CNPJ, RT Capture e Manual foram mantidos, mas ficam sob **Outras formas de prospecção** para não competir com o fluxo Linux.
