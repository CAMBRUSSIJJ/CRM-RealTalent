# V101.10.2 — Prospecting Agent for Linux

## Objetivo

Transformar o Garimpo em um processo automático local, sem depender obrigatoriamente do Google Places. O CRM envia um job ao Agent em `127.0.0.1:4319`; o Agent continua executando em segundo plano, persiste a fila e devolve os resultados para Revisão quando o CRM estiver aberto novamente.

## Fontes e processamento

- **OpenStreetMap / Overpass:** descoberta geográfica automática por segmento e região.
- **Nominatim:** resolução da cidade/região para a área de busca.
- **Sites públicos:** crawler conservador para telefone, e-mail, Instagram e CNPJ.
- **BrasilAPI:** enriquecimento cadastral quando um CNPJ é encontrado.
- **Chromium headless opcional:** usado somente como fallback para sites públicos renderizados por JavaScript, se Chromium/Chrome já estiver instalado no Linux.

O Agent não realiza login, não resolve CAPTCHA, não contorna bloqueios e respeita `robots.txt` nas páginas visitadas.

## Jobs

Cada job mantém:

- segmento;
- regiões;
- meta de resultados;
- estado `queued/running/paused/completed/cancelled/failed`;
- resultados coletados;
- estatísticas de descoberta, duplicidade e cobertura;
- data de criação/início/fim;
- flag de importação pelo CRM.

O estado é persistido em `.realtalent-prospecting-agent/state.json`.

## Campanhas recorrentes

No Garimpo, a execução pode ser:

- única;
- diária;
- semanal.

Campanhas ficam persistidas no mesmo Agent e podem gerar novos jobs mesmo depois de fechar a aba do CRM, desde que o Agent continue ativo.

## Execução pelo launcher

`./start-linux.sh` inicia o Agent junto com Connect e Communications. O Agent também pode ser instalado como serviço do usuário:

```bash
./install-prospecting-agent-service.sh
```

Depois:

```bash
systemctl --user status realtalent-prospecting-agent
journalctl --user -u realtalent-prospecting-agent -f
```

## Segurança

- bind somente em `127.0.0.1` por padrão;
- CORS limitado a origens localhost;
- URLs privadas/localhost são bloqueadas no crawler;
- máximo de 300 resultados por job;
- payload da API local limitado;
- páginas privadas/login/CAPTCHA não são automatizadas.
