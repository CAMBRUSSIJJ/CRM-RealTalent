# V101.7.1 — Metrics & Calling Structural Redesign

## Contrato visual
A V101.7.1 reduz camadas persistentes e prioriza o objeto de trabalho atual.

### Métricas
`Cabeçalho → Seções analíticas → Filtro → Conteúdo`. Na aba Funil, o gráfico deve ser compacto, os números devem permanecer legíveis e o detalhe da etapa deve ficar no inspector lateral.

### Ligações
`Cabeçalho → Centro operacional → Seção do módulo → View da fila → Busca/Filtro/Exibição → Fila`. Não devem existir múltiplos blocos de KPIs repetindo Retornos/Quentes/Prioridades antes da fila.

### Preparação
Somente uma etapa do wizard é exibida por vez. A navegação primária é `Voltar/Continuar`, e o início da sessão só é permitido no passo final.

### Modo Foco
- Idle: briefing.
- Dialing: estado de conexão + três cartões de contexto.
- Running: roteiro/pergunta em primeiro plano + Assistant seletivo.
- Finished: resultado + resumo + próxima ação.
