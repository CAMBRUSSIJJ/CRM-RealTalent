             /health /readiness /status

`/status` é autenticado com o mesmo token de runtime interno usado pelos proxies locais. `/health` e `/readiness` não expõem segredos.

## Regra de compatibilidade

A lógica anterior do launcher foi preservada em `start-linux-legacy.sh`. O wrapper Linux aceita `--legacy` para fallback temporário. Os markers históricos permanecem no wrapper como manifesto inerte porque gates antigos ainda inspecionam `start-linux.sh` diretamente.

## Repository hygiene

A estrutura nova de documentação foi criada, mas os arquivos históricos na raiz ainda não foram movidos nesta release porque vários audits de regressão referenciam seus paths antigos. A migração física desses documentos deve ocorrer somente junto com a atualização desses contratos.
