# RealTalent Agent V2.0 — Autonomous Agent

Release de consolidação: uma arquitetura canônica para Chat, inteligência local, Project Brain, engenharia autônoma, Browser QA, governança, monitoramento e avaliação.

Principais mudanças:
- manifesto de plataforma V2 e fronteiras de segurança explícitas;
- endpoint de production readiness;
- CLI canônica `realtalent-agent.sh` + compatibilidade com wrappers anteriores;
- arquitetura interna nomeada `production-consolidated-autonomous-agent`;
- versão de runtime 2.0.0;
- documentação de produção separa evidência runtime de atestação completa dos produtos.
