# Playbook Visual Conversation Workspace — V101.11.3-H7

## Princípios
1. O editor principal não é um formulário modal.
2. O mapa ocupa a maior parte da tela.
3. O usuário cria caminhos sem sair do nó em que está trabalhando.
4. Inspector mostra apenas o contexto do nó selecionado.
5. Configurações do playbook ficam separadas do desenho da conversa.
6. Mapa, Estrutura, Script e Simular usam exatamente o mesmo grafo.

## Fluxo de construção
Selecionar nó → `+ Caminho` → escrever resposta/condição → escolher tipo do próximo nó → criar → editar conteúdo no Inspector.

## Autonomia do canvas
- drag livre;
- pan pelo fundo;
- zoom;
- painel de blocos recolhível;
- Inspector recolhível;
- auto-organização opcional.

## Persistência
A fonte canônica permanece `PlaybookGuidance.conversationGraph`. Não há migration nova.
