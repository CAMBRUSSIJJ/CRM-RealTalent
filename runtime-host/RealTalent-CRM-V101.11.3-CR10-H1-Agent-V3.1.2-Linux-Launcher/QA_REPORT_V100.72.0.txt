Comportamentos de segurança/consistência verificados
-----------------------------------------------------
- Call Health em estado "restricted" bloqueia a abertura do discador.
- Alertas de frequência excessiva ficam em "attention" e não retiram a decisão do vendedor.
- Leads restritos não entram automaticamente na fila preparada.
- Sinais detectados podem ser incorporados ao registro do wrap-up.
- A análise nova é local e determinística; não adiciona chamadas a provedores externos.
- Nenhuma nova migration foi criada nesta versão.
- Backup schema permanece compatível com a linha anterior.

Limitação do ambiente
---------------------
A instalação completa das dependências npm não pôde ser concluída no ambiente de
empacotamento por timeout de transporte do registry. Portanto, não são declarados
como executados aqui o build completo do Vite, a suíte Vitest completa nem o
`npm run typecheck` integral do projeto.

O código novo recebeu verificação sintática, auditoria de integração, verificação
das migrations, auditorias de regressão, typecheck isolado do serviço e smoke tests.
Para validação integral no Linux após extrair o ZIP, execute:

  npm install
  npm run check
