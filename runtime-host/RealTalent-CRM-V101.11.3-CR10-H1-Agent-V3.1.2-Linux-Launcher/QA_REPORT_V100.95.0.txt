Limitação deste ambiente
------------------------
O registry npm externo não está acessível neste ambiente. A tentativa de npm ci --offline
falhou porque o pacote xmlchars não existe no cache local. Portanto, não é correto afirmar
que npm ci, Vitest, typecheck completo com node_modules e vite build foram executados aqui.

Para impedir que essa limitação vire uma tela quebrada no Linux do usuário, start-linux.sh:
1. exige Node.js 22.x;
2. instala dependências com npm ci (fallback npm install);
3. executa scripts/linux-release-preflight.mjs;
4. executa npm run build;
5. valida o dist gerado;
6. só então abre a V100.95 em http://127.0.0.1:4178/.

Resultado
---------
O pacote está apto para validação final de runtime no Linux. Se o build real falhar na
máquina do usuário, o launcher interrompe a execução e mostra o erro no terminal em vez de
abrir uma tela de carregamento infinito.
