Proteções Linux
---------------
- Porta dedicada: 4181.
- .env.local existente é preservado.
- Google Places é opcional; ausência da chave não impede o CRM de abrir.
- O launcher executa preflight e build real antes de abrir o navegador.
- O launcher bloqueia o HTML legado "Carregando RealTalent CRM" e dependência esm.sh.
- O launcher confirma que dist/index.html pertence à V100.98 antes de iniciar o CRM.

Limitação de validação deste ambiente
-------------------------------------
O ambiente de geração não possui acesso confiável ao registry npm para completar uma instalação limpa das dependências. Por isso o build Vite/npm completo não foi alegado como executado aqui. O pacote foi deliberadamente configurado para executar npm ci/install, preflight e npm run build no Linux do usuário ANTES de abrir o navegador. Se o build real falhar, o launcher interrompe e mostra o erro no terminal em vez de abrir uma tela quebrada.

Configuração opcional do Google Places
--------------------------------------
Executar:
  chmod +x configure-google-places.sh
  ./configure-google-places.sh
  ./start-linux.sh

A chave é salva apenas em .env.local dentro do diretório local da release e não é incluída no ZIP.

CNPJ
----
A consulta é estritamente individual por CNPJ de 14 dígitos. Não há crawler, enumeração ou varredura em massa no provider cadastral.
