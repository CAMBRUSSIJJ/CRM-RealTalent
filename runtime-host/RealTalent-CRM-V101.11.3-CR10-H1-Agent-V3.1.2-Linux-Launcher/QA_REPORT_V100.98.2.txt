SEGURANÇA / CONTRATOS
- CORS não usa wildcard.
- Serviço escuta 127.0.0.1 por padrão.
- Credenciais Twilio ficam em .env.local, que não é empacotado nesta release.
- configure-realtalent-connect.sh grava .env.local com permissão 600.
- Token não é passado como argumento de linha de comando ao helper de configuração.
- Telefones são normalizados para E.164; código de país padrão configurável (55 por padrão).
- Capacidades não suportadas pelo provider inicial não são anunciadas pela UI.

LIMITAÇÕES DE VALIDAÇÃO DESTE AMBIENTE
- O registry npm não estava acessível no momento do QA: EAI_AGAIN ao resolver registry.npmjs.org.
- Por isso, não foi possível executar aqui uma instalação limpa das dependências e, consequentemente, não foram executados neste ambiente:
  * npm run typecheck completo do projeto;
  * Vitest completo;
  * build Vite real com as dependências reinstaladas.
- O start-linux.sh exige Node.js 22, instala as dependências no computador de destino, executa o preflight, executa npm run build e só abre o navegador após validar o build. Se o build falhar, o navegador não é aberto.
- Uma chamada PSTN real via Twilio não foi executada neste ambiente porque não foram fornecidas credenciais/números Twilio reais. O gateway e seus contratos foram testados localmente sem credenciais.

CONFIGURAÇÃO PARA CHAMADAS REAIS
1. Execute ./configure-realtalent-connect.sh
2. Informe TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, TWILIO_FROM_NUMBER e REALTALENT_AGENT_PHONE_NUMBER.
3. Execute ./start-linux.sh.
4. O fluxo inicial toca primeiro o telefone do vendedor; após o atendimento, o bridge disca para o lead.
