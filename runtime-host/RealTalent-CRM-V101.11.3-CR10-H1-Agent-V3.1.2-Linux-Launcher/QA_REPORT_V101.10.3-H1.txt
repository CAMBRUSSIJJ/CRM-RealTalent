resultados sem coordenadas verificadas não permitem provar que pertencem ao
contorno selecionado. Enriquecimento web/CNPJ dos candidatos encontrados dentro
do território continua funcionando.

Gates globais bloqueados pelo ambiente de montagem
---------------------------------------------------
O ZIP-base não contém node_modules. A tentativa de:

  npm ci --offline --no-audit --no-fund

falhou porque @whiskeysockets/baileys não existe no cache npm deste ambiente.
Por isso os seguintes gates NÃO são declarados como aprovados aqui:

- npm run typecheck
  O tsc global inicia, mas não consegue resolver dependências como react,
  react-dom, lucide-react e @supabase/supabase-js sem node_modules; os erros em
  cascata não constituem uma validação semântica válida da árvore.
- npm test
  indisponível aqui: vitest: not found.
- npm run build
  validate:env passa, mas vite está indisponível: vite: not found.

O start-linux.sh instala/repara as dependências no Linux do usuário e executa o
release:verify antes de abrir o CRM. Portanto typecheck + Vitest + Vite build
continuam sendo gates obrigatórios no ambiente final, não foram removidos nem
marcados artificialmente como aprovados.
