--------------------------
1. Empresa descoberta sem website.
2. Website Discovery encontra domínio por busca web pública.
3. Contact Discovery extrai telefone/e-mail do website validado.
4. CNPJ Discovery encontra CNPJ e valida correspondência cadastral.

6. Reprocessar somente Redes conclui Social posteriormente.
7. Contadores/resultados das outras três tarefas permanecem inalterados.
8. Resultado enriquecido é sincronizado de volta para Revisão.
