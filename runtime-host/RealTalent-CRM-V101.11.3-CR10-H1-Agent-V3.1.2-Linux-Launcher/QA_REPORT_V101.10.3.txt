Gates globais
-------------
NÃO EXECUTADOS NESTE AMBIENTE:
- npm run typecheck
- npm test
- npm run build

Motivo:
A árvore de release não traz node_modules e a tentativa de
`npm install --no-audit --no-fund` excedeu o limite de 120 segundos
do ambiente de montagem sem concluir a aquisição das dependências.

Isto não foi convertido em PASS artificial.

O `start-linux.sh` da release instala/repara as dependências e executa
`npm run release:verify` antes de abrir o CRM no Linux do usuário.

Limite conhecido
----------------
O mapa de cobertura territorial está funcional para visualizar as células
planejadas e executadas. O desenho livre de um polígono customizado ainda
não é aplicado como geometria de entrada nesta release. Ao selecionar
"Área do mapa", a execução usa a geometria geocodificada da região informada.

Segurança
---------
- Agent restrito a localhost.
- Somente fontes e páginas públicas.
- Sem login automático em terceiros.
- Sem resolução de CAPTCHA.
- Sem bypass de autenticação, rate limit ou bloqueios.
- robots.txt preservado no crawler.
- Cobertura/saturação são indicadores operacionais, não promessa de 100% do mercado.
