RealTalent CRM V101.11.3-H21.1-H1 — QA REPORT
Communication Lineage Guard Fix

ROOT CAUSE
----------
O source atual de Comunicação usa o marker sucessor H20.7-H2:
  whatsapp-inbox-create-actions is-h207h2

O launcher scripts/start.mjs ainda exigia apenas:
  whatsapp-inbox-create-actions is-h1911

Isso gerava falso bloqueio de lineage apesar de a capacidade H19.11 estar preservada.

CORREÇÃO
--------
O launcher agora aceita explicitamente:
  - whatsapp-inbox-create-actions is-h1911
  OU
  - whatsapp-inbox-create-actions is-h207h2

Pure Chat, Continuous Chat, WhatsAppChatPanel e channel switch continuam obrigatórios.
