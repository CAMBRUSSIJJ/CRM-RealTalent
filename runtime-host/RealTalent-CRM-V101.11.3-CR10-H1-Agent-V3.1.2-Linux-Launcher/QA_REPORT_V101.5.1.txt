LIMITAÇÃO DO AMBIENTE DE QA
O build completo Vite/Vitest/typecheck do projeto não foi executado neste container porque as dependências npm não estão instaladas e o cache offline não contém xmlchars@2.2.0.
Comando verificado:
  npm ci --offline --ignore-scripts
Resultado:
  ENOTCACHED — https://registry.npmjs.org/xmlchars/-/xmlchars-2.2.0.tgz não está disponível no cache.

O pacote NÃO inclui node_modules parcial. O diretório foi limpo após a tentativa.
O start-linux.sh mantém typecheck, Vitest, build, bundle audit, HTTP smoke e Connect smoke como gates obrigatórios quando as dependências puderem ser instaladas no Linux do usuário.
