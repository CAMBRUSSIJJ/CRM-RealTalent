RealTalent CRM V101.6.6 — Workspace UI Standardization
QA Report

Escopo da release
- Padronização visual/operacional de Agenda e Propostas conforme Meu Dia e Contatos.
- Cabeçalhos compactos, resumo compacto, toolbar limpa, chips de filtros e drawer lateral.
- Novo compromisso com disclosure progressivo via "Mais opções".
- Terminologia visual de Propostas usa "Oportunidade / contato" preservando leadId interno por compatibilidade.
- Nenhuma migração estrutural ampla de regras comerciais nesta release.

Motivo
O pacote de trabalho final não contém node_modules. O launcher start-linux.sh instala/recupera as dependências e executa os gates completos no ambiente Linux do usuário.

Nota de compatibilidade
A alteração visível de "Lead" para "Oportunidade / contato" em Propostas não renomeia o identificador interno leadId nesta versão. Isso é intencional para manter compatibilidade com repositories, Pipeline e dados existentes.
