RealTalent CRM V101.8.4-H12 — WhatsApp Realtime
================================================

Objetivo
- Tornar mensagens novas do WhatsApp, mensagens enviadas e ACKs de entrega/leitura visíveis na Central de Comunicação sem depender do botão Sincronizar.

Arquitetura implementada
- WhatsApp Web -> Communications Gateway -> SSE -> Central de Comunicação.
- Endpoint: GET /api/communications/stream?workspaceId=...
- EventSource com reconexão automática no frontend.
- Heartbeat SSE a cada 15s.
- Debounce de refresh de 90ms.
- Polling de 60s mantido somente como fallback.
- Sincronizar renomeado semanticamente para recuperação de histórico.
- Fast path para mensagens 1:1 @c.us, evitando getChat/getContact quando desnecessário.
