Regressão histórica
-------------------
Todos os audits históricos executados pelo `npm run check` passaram sem `FAIL`
até o início do `typecheck`. Os gates históricos que usavam allowlists rígidas de
versão foram ajustados para reconhecer V101.9.0 como release sucessora sem remover
qualquer validação funcional.

Limitação do ambiente de montagem
---------------------------------
O `npm install --no-audit --no-fund` expirou por timeout de rede e nenhum node_modules
ficou disponível. Por isso o typecheck/Vitest/build completos não puderam ser executados
aqui. O typecheck global começou e parou por módulos ausentes (React/Lucide/Supabase),
não por erros detectados nos arquivos da nova fundação.

O `start-linux.sh` preserva o gate completo no Linux:
  npm install -> preflight -> release:verify -> typecheck -> Vitest -> build -> runtime smokes.
