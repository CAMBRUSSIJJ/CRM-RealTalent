Limitação do ambiente de montagem
---------------------------------
A tentativa de instalar dependências não concluiu dentro do timeout disponível e não gerou node_modules.
Por isso typecheck global, Vitest e build globais não puderam ser concluídos nesta montagem.
O typecheck global chegou a executar e os primeiros erros são de módulos ausentes (React/Lucide/Supabase),
consistentes com a ausência de node_modules.

O start-linux.sh mantém o gate completo no Linux antes de abrir o CRM:
  npm install -> preflight -> release:verify -> typecheck -> Vitest -> build -> runtime smokes.

Observação operacional para Supabase
------------------------------------
Para usar wait/retry/resume realmente durável em um ambiente cloud, a migration 48 e a Edge Function
automation-runner V101.9.5 precisam ser publicadas pelo fluxo normal de deploy do ambiente Supabase.
O launcher local não publica recursos remotos sem credenciais explícitas.
