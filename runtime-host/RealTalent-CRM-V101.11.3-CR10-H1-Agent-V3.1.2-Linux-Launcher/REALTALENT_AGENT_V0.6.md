# RealTalent CRM — Agent V0.6

O CRM continua usando a mesma RealTalent Agent compartilhada com Blue Ocean. V0.6 adiciona acesso direto ao Control Center em `http://127.0.0.1:8791/control`, sem criar outro agente.

O drawer preserva ACT/BUILD/QA, confirmação humana e as 6 tools CRM. O botão Control Center abre status, tarefas, memória, atividade e permissões.
