# RealTalent CRM + RealTalent Agent V1.2

A integração do CRM preserva os fluxos do Agent e passa a expor **Intelligence & Reliability**: Model Router, Context Engine, Sandbox Builder e Visual QA.

## Experiência
O usuário continua falando com uma única RealTalent Agent. O roteamento Program/Mission/Workflow/Builder/QA é uma decisão interna do runtime e não exige que o usuário conheça a hierarquia técnica.

## Preservado
- Governance e checkpoints humanos.
- V1.1 Local AI Runtime.
- Programs, Missions, Workflows, Builder e Browser QA.
- CRM permanece o dono dos dados comerciais; a Agent recebe contexto mínimo/sanitizado.
