# RealTalent Agent V2.4 — Memory & Knowledge Intelligence

Este aplicativo continua conectado ao mesmo cérebro central da RealTalent Agent via `/agent` e App Context Bridge. A V2.4 acrescenta embeddings locais, memória semântica explícita, RAG híbrido e reranking no runtime central; não cria uma IA separada dentro deste produto.

## Contrato
- contexto do aplicativo continua vindo do App Context Bridge;
- Tool-First/Evidence Gate continuam obrigatórios para análises do produto;
- conhecimento recuperado complementa, mas não substitui evidência atual do aplicativo;
- conversa comum não vira memória durável automaticamente;
- gravação durável é explícita e administrável;
- ações de escrita continuam exigindo confirmação/governança.
