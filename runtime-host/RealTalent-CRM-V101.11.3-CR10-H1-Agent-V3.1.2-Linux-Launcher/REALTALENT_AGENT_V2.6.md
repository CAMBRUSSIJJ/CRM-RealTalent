# RealTalent CRM + Agent V2.6 — Learning & Evaluation Intelligence

Esta integração mantém o RealTalent CRM conectado à mesma Agent central. A V2.6 não adiciona mutações de negócio ao CRM: evolui o cérebro compartilhado.

## Capacidades novas
- Failure Memory para erros reais, feedback negativo e reparos do Verifier.
- Regression Dataset versionado com casos builtin e casos promovidos de falhas reais.
- Known-Failure Replay antes de aceitar uma release.
- Feedback explícito no chat: “Útil” / “Algo errado”.
- Learning Release Gate separado do benchmark agregado.
- Comparação entre execuções/modelos/builds.

## Capacidades preservadas
- Grounded App Intelligence / Tool-First.
- Intelligence Core e Model Router.
- Memory & Knowledge V2.4: memória semântica, embeddings, RAG híbrido e reranking.
- Multimodal Intelligence V2.5: percepção visual em duas etapas e grounding por regiões.
- Governança: escrita continua exigindo confirmação.

Nenhuma nova mutação de negócio foi adicionada na V2.6.
