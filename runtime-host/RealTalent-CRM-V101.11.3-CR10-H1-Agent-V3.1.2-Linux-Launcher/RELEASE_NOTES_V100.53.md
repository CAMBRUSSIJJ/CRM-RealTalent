# V100.53.0 — Commercial Consistency & Contextual Navigation

Release derivada de simulação operacional completa do CRM.

## Destaques

- Meeting Outcome Flow na Agenda.
- Reuniões criadas por follow-up viram eventos reais.
- Estados `completed/cancelled/superseded` para atividades.
- Métricas deixam de tratar tarefas suprimidas como produtividade.
- Proteção contra follow-up duplicado após call outcome.
- `opportunity_won` usa estado atualizado do lead.
- Deep links preservam lead, atividade, evento e proposta.
- Viewer pode inspecionar Pipeline em modo somente leitura.
- “Quentes parados” e adiamento para dia útil corrigidos.
- Garimpo com membros reais, batch tracking e idempotência por prospect.
