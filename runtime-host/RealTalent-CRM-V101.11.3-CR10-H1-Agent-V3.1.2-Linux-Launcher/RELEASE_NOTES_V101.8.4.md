# V101.8.4 — Official Communications

Fecha o fluxo de Gmail, Outlook e WhatsApp Cloud dentro da Central de Comunicação.

## Entregue
- Composer oficial inline na conversa.
- Envio Gmail / Microsoft Graph / WhatsApp Cloud sem sair do CRM.
- Dispatch imediato com fallback para fila/cron.
- Sincronização manual da inbox.
- Descoberta automática do WABA e `phone_number_id` no OAuth WhatsApp.
- Subscribe do app ao WABA quando permitido.
- Vínculo inbound com `Lead` + `ContactRecord`.
- `contact_id` em threads/eventos oficiais.
- Setup automatizado `configure-communications.sh`.
- Edge Function autenticada `communication-sync-now`.
