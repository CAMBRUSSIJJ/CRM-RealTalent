## Limitação do ambiente

A tentativa de `npm ci --include=dev` sofreu `TransportTimeoutError`. O `node_modules` ficou incompleto; por isso este relatório **não afirma** que `npm run typecheck`, `npm test` e o build Vite oficial foram executados neste container.

No Linux com acesso normal ao npm, executar:

```bash
rm -rf node_modules
npm ci --include=dev
npm run check
```

O `npm run check` executa syntax audit, integridade das migrations, TypeScript, Vitest e build Vite.
