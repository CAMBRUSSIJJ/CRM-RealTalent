# V100.62.0 — Deal Intelligence

## Fluxo

`CRM Snapshot → Signal/Component Engine → Risk Engine → Deal Health → Recommendation Engine → Action Engine`

### Componentes do Deal Health

1. Atividade
2. Stakeholders
3. Proposta
4. Próximo passo
5. Timing
6. Engajamento

Os pesos são configuráveis. O cálculo normaliza a soma dos pesos, portanto configurações que não totalizam 100 continuam válidas.

## Princípio de explicabilidade

Nenhuma nota é apresentada sem componentes, razões e riscos de origem. A probabilidade RealTalent é um contraponto à probabilidade configurada pelo vendedor; ela não substitui nem grava por cima do campo manual.

## Timeline

O Deal Inspector monta a timeline apenas com ligações, atividades, agenda e propostas existentes. A versão não fabrica eventos como “Deal Health caiu 72 → 61”, porque não existe armazenamento histórico desse score nesta release.

## RealTalent Connect

O arquivo `src/services/realtalent-connect-contract.ts` define o contrato `realtalent.connect.conversation.v1`. A gravação, transcrição e análise de áudio continuam fora do CRM. A integração futura deve validar o payload antes de aplicar sinais à oportunidade.
