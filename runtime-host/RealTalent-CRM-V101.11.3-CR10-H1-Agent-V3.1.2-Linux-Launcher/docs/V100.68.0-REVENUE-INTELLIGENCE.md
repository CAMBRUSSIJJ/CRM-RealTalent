# V100.68.0 — Revenue Intelligence & Forecast

A V100.68 transforma o Forecast de Propostas em uma camada executiva de Revenue Intelligence. O objetivo é responder quatro perguntas sem substituir o julgamento do vendedor:

1. Quanto está realmente comprometido?
2. Quanto o RealTalent espera fechar usando os sinais do Deal Intelligence?
3. O pipeline é suficiente para a meta do período?
4. Quais negócios e responsáveis estão colocando a previsão em risco?

## Princípios

- A categoria e a probabilidade manuais continuam preservadas.
- A categoria RealTalent é uma sugestão explicável e nunca sobrescreve o dado do vendedor.
- Bookings/TCV e receita reconhecida são apresentados separadamente.
- O forecast do mês só considera negócios com data de fechamento no período; negócios sem data são tratados como problema de higiene.
- Negócios marcados manualmente como `omitted` ficam fora dos cenários RealTalent, mas podem gerar sinal de divergência.

## Cenários

- **Commit RealTalent:** fechado + oportunidades com sinais fortes de compromisso.
- **Forecast RealTalent:** fechado + contribuição probabilística calculada negócio a negócio.
- **Best Case:** Commit + oportunidades com chance real de fechamento no mês.
- **Pipeline total:** fechado + todo o pipeline aberto previsto para o mês.

## Pipeline Coverage

Quando existe uma meta comercial de receita para o período, a versão calcula:

- valor ainda necessário;
- cobertura de pipeline em múltiplos (x);
- attainment esperado;
- win rate necessário sobre o pipeline aberto;
- ticket médio dos negócios do mês;
- número aproximado de negócios médios adicionais necessários.

## Forecast Confidence

A confiança é calculada pela qualidade dos sinais de cada oportunidade, incluindo Deal Health, data de fechamento, proposta, Account Coverage, momentum e urgência da próxima ação.

## Forecast Risks

O Risk Engine de forecast identifica, entre outros:

- gap para a meta;
- cobertura insuficiente;
- oportunidades sem data de fechamento;
- Commit com sinais fracos;
- divergência entre categoria manual e sugerida;
- concentração excessiva do forecast em um negócio;
- concentração de valor em oportunidades em atenção/críticas.

## Integrações internas

- **Propostas:** nova experiência completa na aba Análises · Forecast.
- **Deal Intelligence:** fonte de saúde, momentum, riscos e probabilidade RealTalent.
- **Meu Dia:** o forecast exibido usa o mesmo motor da aba executiva.
- **RealTalent Assistant:** perguntas sobre forecast, cobertura e meta usam Revenue Intelligence.
- **Metas:** metas comerciais de receita existentes são usadas como quota do período, quando disponíveis.
