# V100.68.1 — UI Reliability

## Overlay stack

A hierarquia final é intencional:

1. Lead Drawer: 9000
2. Personalização / Notificações: 9200
3. RealTalent Assistant: 9500
4. Call Workspace lazy fallback: 12900
5. Modais: 13000
6. Toasts: 14000

O objetivo é impedir feedback invisível e overlays interativos encobertos.

## Browser actions

`src/lib/browser-actions.ts` concentra ações que dependem de permissões do navegador:

- cópia para área de transferência com fallback;
- normalização de URL externa;
- abertura de nova janela com detecção de bloqueio.

A UI deve sempre mostrar feedback quando uma ação for recusada pelo navegador.

## Topbar

A topbar foi agrupada em `topbar__utility-actions` e `topbar__primary-actions`, reduzindo a dependência da quantidade exata de filhos do grid. Em mobile, busca/workspace ocupam linha própria e as utilidades podem rolar horizontalmente sem estourar a viewport.
