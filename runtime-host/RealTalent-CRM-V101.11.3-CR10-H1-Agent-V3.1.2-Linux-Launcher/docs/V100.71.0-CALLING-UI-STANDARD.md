# V100.71.0 — Calling UI Standard

## Hierarquia de ações

1. **Primary** — avançar o fluxo comercial: começar ligações, ligar agora, salvar e próximo.
2. **Secondary** — ações úteis sem mudança principal de estado: abrir lead, copiar, expandir, personalizar contexto.
3. **Ghost** — cancelar, fechar ou ações de baixa prioridade.
4. **Danger** — encerrar uma chamada em andamento ou excluir um registro.

## Navegação

Todas as navegações internas do Calling usam o sistema `call-tabs`:

- `call-tabs--page`: Operação, Histórico, Inteligência.
- `call-tabs--sub`: Fila, Estratégia da sessão, Configurações.
- `call-tabs--work`: Roteiro, Descoberta, Notas.
- `call-tabs--guidance`: Assistente, Pessoas, Objeções, Battlecards e Histórico.

Seletores de período usam `call-segmented`.

## Interação e acessibilidade

- `role=tablist` e `role=tab` nas áreas de navegação.
- `aria-selected` para aba ativa.
- `aria-pressed` para seletores de período e opções mutuamente selecionáveis.
- `focus-visible` com anel consistente.
- Estados `hover`, `disabled`, `active` e destrutivo com linguagem visual previsível.

## Escopo

A alteração é visual/semântica. Não altera contratos de dados, fila, gravação, transcrição, inteligência, resultados de chamada ou migrations.
