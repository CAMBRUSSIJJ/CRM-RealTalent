# V100.78.0 — Propostas + Catálogo 2.0

## Regra operacional
A aba **Propostas** é uma fila operacional do Pipeline, não um arquivo geral. Por isso ela exibe somente propostas vigentes cujos leads estejam ativos e posicionados em uma etapa reconhecida como Proposta.

Uma etapa é reconhecida quando o nome contém, sem diferenciar acentos ou caixa, um dos termos: `proposta`, `proposal`, `orcamento` ou `quote`.

Ao criar uma nova proposta, o CRM move automaticamente o lead para a primeira etapa de Proposta encontrada no Pipeline. A movimentação usa o mesmo contrato de `moveLead`, preservando atividade de mudança de etapa e automações de `stage_changed`.

Propostas de negócios que saem da etapa de Proposta não são apagadas. Continuam disponíveis como dados históricos, revisões, Buyer Rooms, Revenue Intelligence e Forecast quando aplicável.

## Catálogo
O Catálogo passa a ter busca, filtros por categoria e disponibilidade, edição explícita, duplicação, ativação/desativação, contagem de uso e proteção de exclusão para produtos já usados em propostas.

A duplicação gera um item inativo com sufixo `(cópia)` para que a equipe revise preço e condições antes de disponibilizá-lo.

## Compatibilidade
Não foi necessária migration. O modelo `ProductRecord` e o modelo `ProposalRecord` permanecem compatíveis com dados existentes.
