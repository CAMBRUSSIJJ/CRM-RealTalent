# V100.81.0 — Revenue Intelligence 2.0

## Modelo mental

1. **Receita realizada** responde: quanto foi reconhecido nesta competência?
2. **Receita prevista cadastrada** responde: quanto já foi lançado como previsão de competência?
3. **Bookings** responde: quanto de TCV foi ganho comercialmente?
4. **Pipeline ponderado** responde: quanto o pipeline aberto vale após probabilidade do vendedor?
5. **Forecast RealTalent** responde: quanto é esperado considerando sinais reais do negócio?

Essas métricas não são intercambiáveis e aparecem separadas na interface.

## Dimensões

- **Responsável:** pipeline, expected, bookings, receita e risco.
- **Origem:** receita, bookings e forecast esperado por fonte do lead.
- **Produto:** receita, bookings e forecast esperado por item da proposta.

## Qualidade de dados

Lançamentos sem lead, oportunidade ou proposta são contabilizados no total, porém aparecem como **Receita sem vínculo** e não podem ser atribuídos com precisão a origem/produto.

## Datas

Competências em `YYYY-MM-DD` são tratadas como datas puras. Elas não passam por conversão UTC antes de determinar o mês.

## Conversão

Win rate = ganhos / (ganhos + perdidos) entre negócios encerrados no mês. Enquanto o domínio não possuir `closedLostAt`, perdas usam `updatedAt` como referência operacional.
