# RealTalent Assistant 2.0 — V100.89.0

O Assistant 2.0 funciona como camada contextual sobre os dados já carregados no CRM.

## Contexto
Ao abrir o Assistant em uma rota com `leadId` ou `proposalId`, o motor recebe essa entidade como foco. Comandos como “prepare a ligação”, “resuma o histórico” e “qual a próxima ação?” deixam de exigir que o vendedor repita o nome da empresa.

## Capacidades
- análise de pipeline e risco;
- resumo do negócio e histórico recente;
- preparação de ligação;
- próxima melhor ação;
- resumo de reunião registrada;
- sugestão de mensagem;
- Revenue Intelligence;
- plano de follow-up controlado.

## Segurança operacional
O provider atual é local e determinístico. Mensagens são apenas rascunhos. Ações de escrita continuam fora do provider e passam por revalidação e confirmação do usuário.

## Limite desta versão
V100.89 não conecta um LLM externo e não é a “IA própria” planejada para V100.90. A finalidade desta release é preparar UX, contexto, permissões e ferramentas de forma segura.
