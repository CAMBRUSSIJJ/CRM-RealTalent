# V100.91.0 — Central de Ajuda + Onboarding

A V100.91 transforma a ajuda do CRM em uma camada de produto compartilhada entre interface e RealTalent Assistant.

## Arquitetura

`services/help-center.ts` é a fonte única para artigos, palavras-chave, passos e tours. A Central de Ajuda consulta essa fonte; o Assistant usa a mesma busca para responder perguntas de uso do CRM.

## Central de Ajuda

O botão `?` abre pesquisa, categorias, ajuda contextual para a rota atual, artigos passo a passo e tours. Artigos podem navegar diretamente para a função correspondente ou abrir o Assistant com uma pergunta contextual.

## Tours

`GuidedTourOverlay` é montado no `AppShell`, persiste progresso local e navega pelas rotas reais. Tours iniciais: Primeiro ciclo comercial, Gestão da operação e RealTalent AI com segurança.

## Onboarding

Após a configuração inicial do modo local, o CRM marca o primeiro tour como pendente. O tour é aberto quando o AppShell é montado, sem bloquear o acesso ao produto.

## RealTalent Assistant

Perguntas com padrões como `como faço`, `como usar`, `onde encontro`, `tutorial` e `configurar` entram na intenção de ajuda. A resposta é construída a partir da base embarcada de documentação. Nenhuma permissão adicional de escrita é concedida.
