# V100.92.0 — Hardening & UX

## Busca global

O Topbar possui busca global com `Ctrl/⌘ K`. A busca normaliza acentos e consulta módulos, leads, contas, contatos, propostas, atividades, eventos, playbooks, metas e automações. Resultados carregam rota e contexto para abrir o registro correto.

## Navegação progressiva

A navegação principal prioriza o fluxo diário. Território, Follow-ups, Ligações, Playbooks, Metas e Automações ficam no grupo recolhível **Mais ferramentas** e abrem automaticamente quando uma rota secundária está ativa. Preferências de visibilidade e ordenação continuam respeitadas.

## Limpeza operacional segura

`clearOperationalData` virou um contrato do repositório. No modo local, a alteração é aplicada em uma única atualização da base. No Supabase, a aplicação usa `clear_organization_operational_data`, uma RPC administrativa transacional que remove dados operacionais e registra a ação em `audit_logs`, preservando a estrutura do workspace.

## Contratos Supabase

A tipagem local cobre as tabelas e RPCs chamadas pela aplicação, incluindo Account 360, Buyer Room, Webhooks, Calendar e a nova RPC de limpeza.

## UX e acessibilidade

A release adiciona suporte tipado/visual a `warning`, aliases semânticos de CSS e foco visível na busca global. A Central de Ajuda deixa de retornar conteúdo apenas por compartilhar a rota quando o texto pesquisado não corresponde ao artigo.

## QA

Execute `npm run syntax:audit`, `npm run integration:audit`, `npm run migrations:verify` e `npm run qa:v100.92.0`. Com as dependências instaladas, complete com `npm run typecheck`, `npm run test` e `npm run build`.
