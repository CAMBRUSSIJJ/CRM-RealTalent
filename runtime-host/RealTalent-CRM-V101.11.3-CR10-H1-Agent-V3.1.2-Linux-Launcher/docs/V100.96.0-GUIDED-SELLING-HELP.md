# V100.96.0 — Guided Selling & Help

## Propósito

A V100.96 acrescenta uma camada de orientação comercial explicável ao CRM. O sistema não substitui a decisão do vendedor: ele destaca sinais derivados dos dados existentes, explica o motivo e oferece atalhos para executar ou investigar a recomendação.

## Guided Selling

O componente `GuidedSellingStrip` é montado no `AppShell`, abaixo da Topbar. Ele usa os serviços já existentes `buildWorkdayQueue` e `buildDealPortfolio`, respeitando as preferências comerciais e o usuário em foco.

Cada sinal contém:

- contexto/eyebrow;
- título e detalhe;
- métrica quando aplicável;
- explicação acessível por **Por quê?**;
- ação direta para a rota correta;
- pergunta contextual para o RealTalent Assistant.

Rotas cobertas: Meu Dia, Leads, Pipeline, Comunicação, Propostas, Follow-ups, Ligações, Agenda, Métricas, Território, Garimpo, Metas, Playbooks e Automações.

## Central de Ajuda

A Central de Ajuda passa a ter quatro modos:

1. **Jornada do vendedor** — oito etapas do processo comercial.
2. **Ajuda desta tela** — artigos filtrados pela rota atual.
3. **Biblioteca** — busca e categorias existentes.
4. **Tours guiados** — tours já existentes preservados.

A jornada explica o objetivo comercial de cada etapa e mantém dois atalhos obrigatórios: **Ir para a função** e **Perguntar ao Assistant**.

O progresso da jornada é local e não altera dados comerciais.

## Segurança funcional

- nenhuma escrita comercial é feita automaticamente pelo Guided Selling;
- recomendações são explicáveis;
- ações que escrevem dados continuam usando os fluxos existentes e suas confirmações;
- nenhuma migration de banco foi necessária nesta versão.
