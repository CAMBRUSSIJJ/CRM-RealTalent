# V100.98.1 — Workspace Layout Studio

## Objetivo

Resolver o comportamento inconsistente da Sidebar e permitir personalização de tamanho dos blocos sem liberar dimensões arbitrárias que possam quebrar o CRM.

## Sidebar Studio

Em **Configurações → Navegação** o usuário pode definir:

- Sempre expandida, sempre compacta ou automática;
- largura expandida de 224 px ou 252 px;
- exibição da marca e versão;
- exibição dos grupos Operação / Estratégia / Sistema;
- exibição do perfil no rodapé;
- estado inicial de Mais ferramentas;
- posição de cada módulo em Menu principal / Mais ferramentas / Oculto;
- ordem e nome de cada item.

O modo automático mantém a Sidebar expandida quando há espaço e a compacta em notebooks/tablets. A escolha explícita do usuário vence os antigos overrides responsivos.

## Layout Studio

A primeira página habilitada para dimensionamento é **Meu Dia**. Ela usa uma grade segura de 12 colunas.

Tamanhos disponíveis são definidos pelo próprio bloco. Um bloco crítico não recebe opções que tornariam seu conteúdo ilegível.

- Médio: 6 colunas;
- Amplo: 8 colunas;
- Linha inteira: 12 colunas.

Abaixo de 1220 px os blocos voltam automaticamente para linha inteira para preservar legibilidade.

### Organização automática

O botão **Organizar automaticamente** restaura a ordem canônica e usa um layout equilibrado, com os blocos finais de resumo/continuidade lado a lado quando houver espaço.

## Compatibilidade

Preferências antigas são migradas na leitura. `sectionSizes` recebe defaults seguros para layouts já salvos e nenhum bloco existente é ocultado automaticamente.
