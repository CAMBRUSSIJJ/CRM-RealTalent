# V101.10.3 — Garimpo Search & Processing Engine

## Arquitetura

`SearchCampaign → SearchPlanner → TerritoryEngine → SearchCell → ProviderRun → RawCompany → CompanyResolver → CompanyCandidate → EnrichmentPipeline → Validation → Review → CRM`

## Territory Engine
Cada região é geocodificada. Em modo Raio, o centro é convertido em bounding box e a área é dividida em células. O modo de cobertura usa mais células; rápido usa uma célula; econômico usa grade reduzida. Células densas podem ser subdivididas uma vez, respeitando limite de segurança.

O frontend renderiza as células sobre OpenStreetMap, distinguindo pendente, em execução, concluída e falha. O mapa é uma visualização de cobertura nesta release; desenho livre de polígono customizado ainda não altera o plano territorial.

## Search Planner
O termo original é preservado e ampliado por dicionário de categorias. Exemplo para barbearias: `barbearia`, `barber shop`, `barber`, `cabeleireiro masculino`, `salão masculino`, `corte masculino`. O OSM usa seu mapeamento semântico de tags e a descoberta web percorre os termos expandidos.

## Cobertura e saturação
- **Cobertura territorial**: proporção das células planejadas percorridas.
- **Saturação**: estimativa baseada no ganho marginal recente de empresas únicas.
- **Fontes concluídas**: providers executados, separado de cobertura territorial.

Nenhum indicador promete cobertura absoluta do mercado.

## Company Resolver
A resolução usa identificadores fortes (CNPJ, domínio, telefone, Instagram) e sinais adicionais (nome/cidade e proximidade geográfica). Correspondências fortes são mescladas; possíveis duplicidades ficam marcadas para revisão.

## Enrichment Pipeline
Os candidatos recebem estágios independentes: identidade, website, contatos, dados legais, redes sociais, localização e validação. Website usa retries limitados. Informações extraídas mantêm evidência com fonte, data e confiança.

## Qualidade
- **Completude**: quantos campos comerciais relevantes foram encontrados.
- **Confiança**: força dos identificadores disponíveis.
- **Qualidade**: pronto ou atenção, sem esconder os dois indicadores principais.

## Compatibilidade
O runtime H3 (fallback Nominatim → área Overpass, descoberta web, diagnóstico de rede, robots.txt e políticas de segurança) é preservado. O estado antigo é normalizado para schema v2 no carregamento.
