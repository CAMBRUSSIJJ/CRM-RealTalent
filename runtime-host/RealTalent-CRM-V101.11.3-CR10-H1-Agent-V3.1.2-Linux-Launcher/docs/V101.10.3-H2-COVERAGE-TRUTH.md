# Coverage Truth

A cobertura do Garimpo distingue:

- `attemptedTerritoryPercent`: parcela do plano já tentada;
- `successfulTerritoryPercent`: parcela concluída com provider válido;
- `failedTerritoryPercent`: parcela cujo processamento falhou;
- `territoryPercent`: alias retrocompatível de `successfulTerritoryPercent`;
- `saturationPercent`: ganho marginal calculado somente com execuções válidas;
- `saturationConfidence`: confiança baseada na proporção de runs válidas/falhas.

Uma campanha pode terminar com 100% tentado e menos de 100% de cobertura bem-sucedida. Isso deve ser apresentado como cobertura parcial, nunca como busca completa.
