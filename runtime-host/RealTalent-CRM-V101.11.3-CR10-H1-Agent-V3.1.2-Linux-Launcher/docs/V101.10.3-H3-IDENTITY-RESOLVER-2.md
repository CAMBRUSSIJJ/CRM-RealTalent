# Identity Resolver 2.0

O resolver distingue identidade empresarial de sinais compartilháveis.

## Strong identity
- CNPJ idêntico;
- identidade estável do provider (por exemplo OSM ID).

## Evidências auxiliares
Domínio, telefone e Instagram não resolvem uma empresa sozinhos. São combinados com nome, endereço e proximidade geográfica. Isso evita fundir filiais, franquias ou unidades de uma mesma rede.
