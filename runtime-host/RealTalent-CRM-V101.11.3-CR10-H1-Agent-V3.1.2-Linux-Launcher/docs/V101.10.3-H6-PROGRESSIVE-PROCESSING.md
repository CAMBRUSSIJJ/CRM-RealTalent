# V101.10.3-H6 — Progressive Processing

## Objetivo
Permitir que empresas prontas sejam publicadas na Revisão enquanto o Garimpo ainda percorre território e executa enriquecimentos.

## Contrato
- cada candidato pronto recebe `reviewRevision`;
- `GET /jobs/:id/review?afterRevision=N` entrega apenas revisões novas;
- o CRM importa/upserta localmente e somente depois envia ACK;
- `POST /jobs/:id/review/ack` persiste o cursor confirmado;
- no fechamento, somente candidatos ainda não sincronizados são importados;
- reprocessamento de enrichment republica o candidato quando ele permanece/pronto;
- candidatos com atenção continuam chegando no fechamento da campanha.

## Segurança operacional
O ACK progressivo não marca o job inteiro como importado. O marcador `clientImportedAt` continua reservado ao fechamento terminal.
