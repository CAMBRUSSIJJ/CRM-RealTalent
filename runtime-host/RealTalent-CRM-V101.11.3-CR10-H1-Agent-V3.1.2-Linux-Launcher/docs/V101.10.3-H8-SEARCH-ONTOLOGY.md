# V101.10.3-H8 — Search Ontology

O H8 transforma o texto livre do segmento em uma intenção estruturada antes de consultar fontes externas.

## Contrato

Cada intenção pode definir:

- `aliases`: maneiras comuns de pedir o segmento;
- `webTerms`: consultas expandidas para descoberta web;
- `osmFilters`: tags compostas para OpenStreetMap/Overpass;
- `osmNameTerms`: fallback lexical no OSM;
- `cnaes`: códigos e descrições de atividade econômica usados como referência de enriquecimento/validação;
- `providerCategories`: categorias semânticas para adapters de providers futuros.

O `SearchPlan` persiste a ontologia resolvida, incluindo `intentId`, confiança e versão. Segmentos sem mapeamento continuam funcionais via intenção `generic`, sem inventar CNAE.

## Exemplo

`empresa de climatização` resolve para `hvac`, com termos como `instalação de ar condicionado`, `HVAC` e `refrigeração comercial`; no OSM o planner usa `craft=hvac`, e o plano registra CNAE `4322-3/02` como referência setorial.

## Compatibilidade

H1–H7 permanecem preservados. Não há migration SQL nova; o Agent normaliza jobs persistidos para schema de estado 5 e reconstitui a ontologia quando necessário.
