# RealTalent CRM V101.10.5 — Selection & Filter System

## Objetivo
Unificar caixas de seleção, dropdowns, filtros, multi-seleção e operações em lote em um sistema canônico reutilizável em todo o CRM.

## Primitives
- `SelectionSelect`: select/combobox com portal, collision detection, busca e teclado.
- `MultiSelection`: multi-select com resumo compacto em vez de chips que quebram linha.
- `EntityPicker`: busca contextual de pessoa/empresa/responsável.
- `FilterSelection`: variante compacta para filtros.
- `SelectionCheckbox`: checkbox com estado parcial.
- `SelectionToolbar`: barra contextual para operações em massa.

## Rollout V101.10.5
Migração funcional prioritária em Garimpo, Contatos, Pipeline e Meu Dia. Os demais módulos recebem um bridge visual global para manter altura, borda, foco, seta, estados disabled/hover e checkbox consistentes enquanto a substituição funcional ocorre progressivamente.

## Regra de arquitetura
Novos fluxos não devem criar dropdown/select/checkbox ad-hoc quando uma primitive do Selection System atender ao caso.
