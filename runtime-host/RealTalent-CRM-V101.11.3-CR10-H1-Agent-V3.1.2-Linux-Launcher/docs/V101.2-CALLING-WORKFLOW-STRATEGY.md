# V101.2 — Calling Workflow & Strategy

## Modelo mental

O fluxo de Calling passa a ser:

**Strategy Hub → Preparar sessão → Conversar → Registrar resultado**

O usuário não precisa dominar a terminologia interna de Service/Sales Enablement para ligar. Na operação diária ele escolhe um **Roteiro**; o objeto Playbook continua sendo a fonte estruturada por trás desse roteiro.

## Strategy Hub

A visão Estratégia em Playbooks armazena preferências por workspace:

- objetivo padrão;
- modo Focus ou Power;
- seleção automática ou manual do roteiro;
- Assistant durante a conversa;
- histórico apenas sob demanda;
- autosave das notas;
- Call Health por exceção.

O CRM continua permitindo override por sessão.

## Context Workspace

Durante uma ligação, informações do lead ficam em um bloco recolhível com três abas:

- **Resumo:** empresa, contato, etapa/oportunidade, última interação e notas fixadas;
- **Histórico:** chamadas, atividades e agenda ordenadas por data;
- **Notas:** rascunho local, autosave e fixação de informação importante.

A intenção é preservar espaço cognitivo: nenhum desses painéis compete permanentemente com o roteiro.

## RealTalent Phone

O RealTalent Phone é um companion web de rede local entregue pelo próprio `realtalent-connect-server.mjs`. Ele não é um aplicativo nativo Android/iOS e não tenta contornar as limitações do sistema operacional.

### Pareamento

- código numérico temporário;
- token aleatório criado após pareamento;
- registro local persistente em `.realtalent-phone-devices.json` com permissão restrita;
- heartbeat por polling;
- o CRM enxerga apenas dispositivos online recentes.

### Fluxo de chamada

CRM cria uma chamada com `deviceId=connect:phone:<id>` → Connect cria um comando → Phone faz polling → Phone exibe lead → usuário abre `tel:` → usuário confirma estado → Connect publica o estado pela mesma Voice API consumida pelo CRM.

### Estados sincronizados

- `connecting`
- `ringing`
- `connected`
- `failed`
- `ended`

O botão do CRM usa **Registrar término** quando o canal é RealTalent Phone, pois encerrar a sessão no CRM não pode desligar uma chamada SIM nativa.

## Provider PSTN

O Twilio Agent Bridge permanece preservado. Quando configurado, ele oferece uma ligação realmente iniciada e encerrada pelo provider, independentemente do companion de celular.
