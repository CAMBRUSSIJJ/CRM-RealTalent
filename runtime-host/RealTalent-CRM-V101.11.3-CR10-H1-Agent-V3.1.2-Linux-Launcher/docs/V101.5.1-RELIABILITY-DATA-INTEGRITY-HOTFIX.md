# V101.5.1 — Reliability & Data Integrity Hotfix

## Objetivo

Corrigir os riscos de produção identificados na auditoria da V101.5.0 antes de adicionar inteligência contextual ou novos módulos.

## Invariantes introduzidos

1. Uma sessão de Calling só pode ser recuperada no mesmo workspace e pelo mesmo usuário.
2. Um draft de áudio pertence a uma tentativa (`attemptId`) específica.
3. Depois que a RPC comercial comitou uma chamada, o Storage não pode apagar a gravação em um erro secundário.
4. `owner_id` é a fonte de verdade para responsável; `ownerName` é derivado.
5. `null companyId` nunca cria uma relação implícita entre entidades.
6. Um disclosure deve obedecer ao próprio estado de expansão em qualquer modo visual.

## Fora de escopo

Esta release não resolve ainda o refresh integral do snapshot, a paginação/lazy URL de chamadas, a consolidação dos vários CSS de Calling, nem a suíte E2E completa. Esses itens permanecem para V101.5.2/V101.5.3.
