# V101.6.3 — Contact Views 2.0

## Princípio
A tela de Contatos passa a funcionar como uma base com múltiplas views. O usuário não navega entre páginas diferentes: ele observa o mesmo conjunto de contatos por configurações diferentes.

## Modelo de view
Cada view armazena:
- nome;
- cor;
- ícone;
- tipo: tabela, quadro ou lista compacta;
- filtros;
- colunas;
- densidade;
- ordenação;
- agrupamento por etapa;
- visibilidade privada/workspace;
- posição;
- flag de padrão.

## Starter views
Na primeira execução são criadas quatro views editáveis:
1. Todos os contatos;
2. Contatos quentes;
3. Retornos pendentes;
4. Sem próxima ação.

Elas não são mais hard-coded. Se o usuário excluir uma starter view, ela fica arquivada para não ser recriada automaticamente.

## Reordenação
Views próprias podem ser arrastadas entre si ou movidas pelo menu contextual. Views compartilhadas de terceiros podem ser usadas e duplicadas, mas não alteradas.
