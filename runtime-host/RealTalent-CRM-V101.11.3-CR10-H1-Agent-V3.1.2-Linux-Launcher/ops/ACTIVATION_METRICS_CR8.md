# CR8 — Activation Metrics

Métricas para os primeiros clientes devem medir adoção, não conteúdo.

- **Time to First Value**: tempo entre criação do workspace e conclusão do primeiro fluxo comercial útil.
- **Workspace Activation**: empresa configurada + pelo menos 2 usuários ativos + Pipeline disponível.
- **Invite Acceptance Rate**: convites aceitos / convites válidos enviados.
- **First Workflow Completion**: contato → oportunidade → próxima ação registrada.
- **Commercial Completion**: proposta criada e avançada pelo fluxo permitido.
- **7-day Active Team**: usuários únicos ativos em 7 dias, por workspace.
- **Recovery Rate**: falhas recuperáveis concluídas após retry/retomada.
- **Support First Response**: tempo até primeira resposta humana no canal definido.

Princípio de minimização: **não coletar conteúdo** de mensagens, notas, propostas, nomes de clientes ou corpo de comunicações para essas métricas. Use IDs técnicos pseudonimizados, contagens, timestamps e estados quando telemetria remota for habilitada.
